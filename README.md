Nom et description du projet : Application de dessin canvas
Ce projet est une application de dessin en javascript. 
L’utilisateur peut dessiner avec un pinceau, changer les couleurs, effacer, ajuster la taille du trait, nettoyer le canvas ou sauvegarder son dessin en image (format .png).

Technologies utilisées: 
HTML / CSS / JS /Canvas API 2D/ Git / GitHub

Fonctionnalités principales: 
- Dessiner avec un pinceau
- Choisir parmi plusieurs couleurs
- Gomme pour effacer
- Régler la taille du trait
- Bouton Clear pour effacer tout le dessin
- Bouton Save pour sauvegarder en PNG
- Interface avec toolbar (boutons, couleurs, slider)

Lien vers la page GitHub Pages (rendu final): https://kaisserbaccar.github.io/Baccar_Kaisser_Application-de-dessin-Canvas-/

Nouveautés explorées : comment utiliser la Canvas API (beginPath, stroke, lineTo…) , comment gérer les événements souris pour dessiner en continu,
comment sauvegarder le canvas en PNG via toDataURL(), comment faire un outil gomme et un outil pinceau

Difficultés rencontrées : Les couleurs ne s'affichaient pas , problème de design quand la toolbar changeait de taille , Le canvas ne dessinait rien (taille non définie → width/height manquants)

Solutions apportées : Recherche de solutions (MDN Canvas API, StackOverflow, ChatGPT), test et débogage sur Chrome DevTools
